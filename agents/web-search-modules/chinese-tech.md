# Chinese Tech Module

> Dedicated strategy for Chinese tech communities

**Trigger scenarios**: Chinese tech issues, domestic frameworks, China-based solutions, or when English sources are insufficient

## Search sources
- **CSDN** (csdn.net) - large IT community with extensive technical articles and solutions
- **Juejin** (juejin.cn) - high-quality developer community with modern tech focus
- **SegmentFault** (segmentfault.com) - Q&A platform similar to Stack Overflow
- **Zhihu** (zhihu.com) - knowledge-sharing platform with technical discussions
- **Cnblogs** (cnblogs.com) - blogging platform with deep technical content
- **OSChina** (oschina.net) - open source community and technical news
- **V2EX** (v2ex.com) - developer community with active discussions
- **Tencent Cloud** and **Alibaba Cloud** developer communities - enterprise-level solutions

## Query strategy (Bilingual Research)
- **For bilingual research**: Generate queries in both English and Chinese
- Use Chinese technical terms and common translations (e.g., errors, solutions)
- Search Chinese sites with Chinese keywords for better results from Chinese developer communities
- When relevant, translate key findings to English with context
- Cross-reference Chinese solutions with English sources when possible

## Notes
- Prioritize official documentation and well-maintained articles
- Pay attention to version compatibility (Chinese content may lag behind latest versions)
- Translate technical terms accurately
