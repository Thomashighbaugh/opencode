# X (Twitter) Module

> Strategy for researching on X/Twitter

**Trigger scenarios**: Breaking news, announcements, maintainer statements, hot takes, thread deep-dives

## Search sources
- **X search** (x.com/search)
- **Nitter instances** (nitter.net, nitter.projectsegfau.lt) - often more accessible for research
- **Thread readers** (threadreaderapp.com) - unroll long threads
- **Advanced search** - filter by date, from:username, has:links

## Query strategy
- Search "[topic] (from:maintainer OR from:org) min_faves:10"
- Look for **threads** (long-form explanations) - use thread unrollers
- Prioritize posts from **maintainers/core contributors**
- Look for quote posts with added context
- Check dates - very recent vs historical
- Search for "[error message]" or specific technical terms
- Look for announcements of releases/fixes
- Consider searching both X and alternatives for important statements

## Information extraction
- Capture full thread context (use thread readers)
- Note who posted (role/credibility)
- Extract linked resources
- Distinguish speculation from announcements
- Look for follow-ups/corrections
- Save important threads before they disappear
