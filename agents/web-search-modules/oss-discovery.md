# OSS Discovery Module

> Finding open source projects, tools, libraries, comparisons

**Trigger scenarios**: "find tools for X", library comparisons, alternative discovery, ecosystem mapping

## Search sources
- **GitHub** (github.com) - repos, topics, trending, awesome lists
- **GitLab**, **Codeberg** - alternative hosts
- **Awesome lists** (awesome.re, github.com/sindresorhus/awesome)
- **AlternativeTo** (alternativeto.net) - app alternatives
- **LibHunt** (www.libhunt.com) - library discovery
- **BestOfJS** (bestofjs.org) - JS ecosystem rankings
- **DevDocs** references for comparisons
- **StackShare** (stackshare.io) - tech stack usage
- **crates.io/npm/pypi** pages for adoption signals

## Query strategy
- Search "[task] library alternative open source"
- Look for "awesome-[topic]" lists
- Check GitHub stars/forks/last commit/activity
- Look for recent activity vs abandoned
- Find comparison articles
- Check license compatibility
- Look for adoption in production (mentions in blogs/reddit)

## Information extraction
- Repo URL, stars, last updated, license
- Language/framework, dependencies
- Active maintenance signals
- Community size
- Comparison to alternatives
- Pros/cons from real usage
