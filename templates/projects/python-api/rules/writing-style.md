# Writing Style

**Scope:** prose authored in this project — responses, docs, READMEs, code comments, summaries. **Not** code, diffs, or file contents; **not** text the user asked for verbatim. Yields to any explicit user instruction and to the project's output-format rules.

**Posture:** defaults applied with judgment, never bans. When writing for an external audience, that genre's conventions come first; these rules fill the gaps.

## Two principles

1. **Say it, don't announce it.** Start with the point. Delete any clause that labels what the next clause does.
2. **The words carry the meaning; the polish doesn't.** Plain word over inflated word: `utilize` → `use`, `leverage` → `use`, `delve into` → `look at`, `in order to` → `to`, `serves as` → `is`.

## Content

- "marking a pivotal moment in…" → state what happened.
- "Experts believe it plays a crucial role" → name the source, or flag the claim.
- "nestled in the heart of a thriving ecosystem" → say where it is, with a number if the source has one.
- "the future looks bright", "only time will tell" → cut.
- **Never invent a specific.** A fabricated number, name, date, or mechanism is worse than the vague phrasing it replaced.

## Language

**Always review:** `delve`, `tapestry`, `realm`, `landscape` (metaphor), `robust`, `comprehensive`, `cutting-edge`, `seamless`, `pivotal`, `underscores`, `testament to`, `game-changer`, `watershed`, `ever-evolving`, `holistic`, `at its core`, `best practices`, `actionable`, `impactful`, `learnings`.

**Flag when they cluster in one paragraph:** `harness`, `navigate`, `foster`, `elevate`, `streamline`, `empower`, `revolutionize`, `facilitate`, `crucial`, `nuanced`, `multifaceted`, `myriad`, `ecosystem`, `transformative`, `paramount`, `poised`.

Fix with the plain word or, better, a specific — a number, a comparison, an example.

## Sentences and structure

- **No colon-hinged labels** ("the clear shape: …") — use two sentences or a connective.
- **No verbless fragment openers** ("Two things worth watching.") — merge into the sentence.
- **No "not X, but Y" as a rhythm** — contrast only genuinely competing explanations.
- **Keep verbs as verbs.** One metaphor per sentence; never stack two compressed phrases.
- Subject before verb before object; clear antecedents.

## Openers and closers

- **Cut chatbot artifacts** — "I hope this helps!", "Great question!", "Let's explore", "Let me break this down".
- **Cut filler hedges** — "It's worth noting", "Interestingly", "As you can see", "honestly".
- **End when the content ends.** No summarizing or uplifting closer; cut the last sentence if it adds nothing.
- **No engagement bait** — "Let me know if you'd like more".

## Rhythm — removal is half the job

Clearing every flag while erasing cadence and idiosyncrasy is a failed edit. Keep deliberate fragments, "And"/"But" openers, uneven pacing. **Over-polishing pushes human writing toward AI profiles.**

## BAD / GOOD

**BAD:** "Certainly! Let me dive into how this architecture leverages a robust, seamless integration layer to empower teams."
**GOOD:** "The integration layer is one API. Teams call it instead of wiring each service themselves."
