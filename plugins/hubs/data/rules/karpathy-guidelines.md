# Karpathy Coding Guidelines

- **Think before coding**: Understand the problem, consider alternatives, plan the approach before writing code.
- **Simplicity first**: Prefer the simplest solution that works. Avoid over-engineering.
- **Surgical changes**: Make minimal, targeted changes. Don't refactor unrelated code.
- **Goal-driven execution**: Every change should have a clear purpose. Verify each step before proceeding.

> Pattern: `[Step] -> verify: [check]`
