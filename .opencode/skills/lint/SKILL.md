# Lint

Lint and format the project codebase.

## Commands

| Command | Description |
|---------|-------------|
| `npm run lint` | Run lint check |
| `npm run lint -- --fix` | Auto-fix issues |
| Run linter on path | Check specific files/directories |

## Pre-Commit

Run lint before committing to catch issues early.
