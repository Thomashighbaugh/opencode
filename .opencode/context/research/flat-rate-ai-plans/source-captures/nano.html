How Pricing Works

Quick Overview

Pricing is based on tokens (roughly 4 tokens for every 3 words). You pay for input tokens (what you send) and output tokens (what the AI responds).

Text Model Pricing

Text pricing - no markup
Text model usage in both the API and web chat is billed at list prices: GPT-5.5 costs $5/$30 per million tokens at OpenAI, and exactly $5/$30 here. We add no percentage on top, and there are no percentage fees on deposits. Every chat completion and Responses API response includes the exact cost charged, so you can verify this on any request. The only exceptions are opt-in: manually pinning a specific provider adds 5%, and bring-your-own-key requests are billed 5% of the normal model cost.
