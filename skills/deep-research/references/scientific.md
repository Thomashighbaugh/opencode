# Scientific Research — Axes, Probes, and Section Template

Use this file for `type == scientific` research: scientific consensus, methodology review, evidence assessment, replication status. Load after the user confirms scope.

Probe the user: "What scientific question? Are you looking for the current consensus, methodological quality, replication status, or the frontier of what's known?"

## Step 2 axes — Evidence landscape

| Agent | Axis | Key questions |
| --- | --- | --- |
| 1 | **Current consensus** | What does the weight of evidence say? Key meta-analyses, systematic reviews, consensus statements from scientific bodies |
| 2 | **Methodology quality** | How strong is the evidence? Sample sizes, study designs, effect sizes, confidence intervals, p-hacking concerns |
| 3 | **Replication status** | Has the key finding been replicated? Any failed replications? Replication crisis relevance |
| 4 | **Frontier and uncertainty** | What's still unknown? Active debates? Where does the evidence thin out? |

## Step 3 axes — Key evidence

| Agent | Axis | Key questions |
| --- | --- | --- |
| 1 | **Foundational studies** | The papers that established the field — who, when, what did they show, how have they held up |
| 2 | **Recent advances** | Papers from the last 2–3 years — new methods, new findings, paradigm shifts |
| 3 | **Contradictory evidence** | Studies that contradict the consensus — are they methodological outliers or genuine challenges? |

## Step 4 axes — Translation and impact

| Agent | Axis | Key questions |
| --- | --- | --- |
| 1 | **Practical applications** | How has this research been applied? Clinical trials, engineering applications, policy changes |
| 2 | **Funding and incentives** | Who funds this research? Any conflicts of interest? Publication bias indicators |
| 3 | **Public understanding** | How is this science communicated to the public? Common misconceptions? Media coverage quality |
