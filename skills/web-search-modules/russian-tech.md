# Russian Tech Module

> Specialized search strategy for Russian and CIS tech communities

**Trigger scenarios**: Russian-speaking sources, open source projects from Russia/CIS, Russian developer discussions, local tech ecosystem, translations/references

## Search sources
- **Habr** (habr.com) - largest Russian tech community, articles and discussions
- **Habr Q&A** - technical questions and answers
- **TJournal** (tjournal.ru) - tech news and analysis
- **VC.ru** (vc.ru) - business/tech/news
- **Spark-Interfax/other sources** as needed
- **GitHub** - Russian developers/projects
- **X(Formerly Twitter)** - Russian tech community
- **Telegram channels** - mention if relevant (often linked from posts)
- **Cossa.ru, Roem.ru** - IT business news
- **Geektimes** (legacy) references

## Query strategy
- Use both Russian and English queries when researching Russian topics
- Search for translated technical terms (common patterns)
- Look for original Russian discussions when English coverage is lacking
- Check Habr posts with high ratings and comments
- Look for GitHub repos by Russian authors/organizations
- Prioritize primary sources (original posts) over aggregators

## Information extraction
- Translate key findings accurately (technical terms)
- Note original language and provide translation/context
- Distinguish between official announcements and discussions
- Check dates (Russian tech news often has different timing)
- Look for English mirrors/translations of important posts
