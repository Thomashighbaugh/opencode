# Telegram Module

> Strategy for researching via Telegram channels, groups, and public links

**Trigger scenarios**: Announcements from projects/companies, early leaks, community updates, regional communities, real-time info

## Search sources
- **Telegram search** (via web search: site:t.me or search engines indexing t.me)
- **Public Telegram channels/groups** (t.me/channelname)
- **Telegram channel catalogs** (tgstat.com, tlgrm.eu) - discover channels, stats
- **Telemetr.me** - channel analytics/discovery
- **Telegram link aggregators** - find relevant public channels

## Query strategy
- Search for "[topic] site:t.me"
- Look for official project channels vs community channels
- Prioritize official announcements
- Check pinned messages and recent posts
- Look for linked resources (docs, repos)
- Note timestamps - Telegram moves fast
- Be aware: private groups are not searchable

## Information extraction
- Capture announcements with dates
- Extract links shared in posts
- Note if info is first-hand or forwarded
- Check for contradictions between channels
- Archive important links
